## 🌍 Global Impact of COVID-19: Health, Economy, and Policy
📌 Introduction
This project explores global trends during the COVID-19 pandemic through a multi-dimensional data visualization story. Using datasets from Our World in Data and the COVID-19 Data Repository, the project visualizes relationships between case counts, death rates, vaccination rates, economic indicators, healthcare resources, and government policy responses.

Built in Tableau, the project showcases how the pandemic affected countries across continents from 2020 to 2022, offering insights into the interplay of public health and socioeconomic factors.

✅ Tasks Completed
✅ Collected and cleaned data from multiple global sources

✅ Filtered datasets to handle missing/null values

✅ Built 6 Tableau visualizations:

Line Graph – Total COVID-19 Cases Over Years

Scatter Plot – Total Deaths vs. Total Cases

Bar & Panel Line Charts – GDP Per Capita Trends

Area Chart – Hospital Beds Per Thousand Over Time

Dual-Line Graph – Vaccination vs. Death Rates

Scatter Plot – Stringency Index vs. Case Rates

✅ Created interactive Tableau story with narrative context

✅ Analyzed trends, correlations, and anomalies

⚠️ Challenges Faced
Missing or incomplete data in fields like hospital_beds_per_thousand and stringency_index

Null values in the continent field required filtering in all visualizations

Difficulty deriving economic trends due to annual updates to GDP data

Balancing storytelling with statistical clarity across multiple dimensions

🧠 Key Insights
COVID-19's spread accelerated in late 2021, doubling previous global totals

Death tolls tracked closely with rising case counts

Economic damage was visible but hard to quantify due to sparse data

Vaccination campaigns coincided with lower death rates

Stringent policies didn't always guarantee low case numbers, indicating deeper systemic factors at play
